# AGENTS.md

## Purpose of this repository

This directory contains **only daily task checklists** (`Tasks_YYYY-MM-DD.md`).
There is no application code here. Do not add code, documentation, or unrelated files.

## Rules

- Only create or edit task checklist files.
- Do not explore, search for, or modify other projects/directories unless explicitly asked.
- Do not add extra sections, notes, or commentary to task files — tasks only.
- Autocommit and sync/push to githubs in every modification.

## Task file format

File name: `Tasks_YYYY-MM-DD.md` (local date).

```md
# Tasks - Sat Oct 24 2026

## Todos ([ ] for pending, [.] for in progress and [x] for done tasks)

- [ ] Task one
- [.] Task two
- [x] Task three
```

Status markers:

- `[ ]` pending
- `[.]` in progress
- `[x]` done

## Daily workflow

- When asked to review yesterday's tasks, read yesterday's file and report completed, in-progress, and pending items.
- When asked to continue or plan today, create today's file with unfinished tasks carried over.
- When asked to update a task, change only its status marker or text.
